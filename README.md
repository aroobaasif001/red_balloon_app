# Red Balloon App

**Red Balloon App** is a location-based social discovery mobile application designed to help users find and connect with nearby people within a defined radius.

The platform focuses on **nearby user discovery, radius-based location matching, real-time visibility, profiles, communication, and social interaction**, creating a smooth way for users to discover people around them.

## Key Features

### Location-Based Discovery
- Users can discover nearby people based on their current location
- Results are filtered within a defined distance/radius
- Helps users connect with people who are physically close to them

### Radius-Based Matching
- Nearby users are shown according to selected or predefined radius logic
- Supports more relevant and accurate local discovery
- Useful for community, social, and location-based networking experiences

### User Profiles
- Users can create and manage personal profiles
- Profile information helps others understand and connect better
- Designed to support meaningful user interaction

### Real-Time Nearby Visibility
- Location-aware system displays users available nearby
- Helps improve instant discovery and local engagement
- Built around accurate proximity-based interaction

### Chat & Communication
- Users can connect and communicate with nearby people
- Supports smooth interaction after discovery
- Helps turn local discovery into real social engagement

### Privacy-Focused Location Experience
- Location is used to show nearby users within radius
- Designed with controlled visibility and user-based interaction
- Supports a safer and more intentional discovery flow

## Technology Stack

- **Flutter & Dart** — Cross-platform mobile application development

- **Real-Time Database / Backend Integration** — User availability and location-based data handling
- **Chat System** — User-to-user communication
